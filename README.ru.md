# TMail

[English](README.md) · **Русский**

Полноценный почтовый сервер с современной веб-почтой и ИИ-помощником, который ставится на свой
Linux-сервер одной командой.

* **Почтовый сервер**: Postfix (SMTP), Dovecot (IMAP/POP3, квоты, фильтры), Rspamd (антиспам,
  DKIM-подпись, проверка SPF/DKIM/DMARC), ClamAV (антивирус: вложение нельзя скачать, пока оно не
  проверено), сертификаты Let's Encrypt, PostgreSQL как единственный источник данных.
* **Веб-почта**: интерфейс как у Gmail на 100 языках, цепочки писем, быстрый поиск (в том числе
  внутри вложений), просмотр PDF/Office/картинок, большие файлы ссылками (Garage S3), ярлыки, папки
  с автосортировкой, календарь с напоминаниями, шаблоны, подписи с картинками, отложенная отправка
  с отменой, проверка орфографии, уведомления в браузере, тёмная тема, версия для телефона.
* **Несколько ящиков на одного сотрудника**: один вход — много ящиков, ответ уходит с адреса, на
  который пришло письмо. Сборщик внешних ящиков (Gmail, любой IMAP/POP3) с отправкой через их SMTP.
* **ИИ-помощник** (по желанию, любой API, совместимый с OpenAI: OpenAI, OpenRouter или своя модель
  на vLLM/Ollama): ответы, краткое содержание, редактирование, диктовка, автоответы, сортировка и
  карточки компаний и людей из писем и вложений. Промпты редактируются в админке. Доступ по MCP для
  внешних ИИ-агентов.
* **Администрирование**: пользователи и роли, ящики, псевдонимы, домены с живой проверкой DNS,
  сборщик, антивирус, состояние сервера, журнал. Сторож, fail2ban, межсетевой экран и шифрованные
  инкрементные резервные копии настраивает установщик.

## Для компаний, где с одной почтой работают несколько сотрудников

Почти в каждой компании есть ящики, на которые отвечают несколько человек: `sales@`, `support@`,
`info@`, `zakaz@`. TMail построен вокруг этого:

* **Один вход — много ящиков.** Сотрудник входит один раз и видит все ящики, к которым ему дали
  доступ, — вместе в одном списке или по отдельности. Доступ выдаётся на каждый ящик (только чтение
  или с отправкой) и забирается одним нажатием; пароль от ящика никому не передаётся.
* **Ответ уходит с нужного адреса** — с того ящика, на который пришло письмо, с его подписью.
* **Видно, кто ответил.** У отправленных писем указан сотрудник; переписка, прочитанность, ярлыки и
  папки общие для команды и обновляются сразу.
* **Внешние ящики тоже.** Gmail или любой IMAP/POP3-ящик подключается и используется командой так же,
  отправка — через его собственный SMTP.
* Плюс карточки компаний и людей из переписки: вся команда видит, кто написал, его компанию, ИНН и
  телефоны.

## Требования — лёгкий по устройству

TMail сделан для небольших серверов. Каждая часть подобрана и настроена по памяти: бэкенд веб-почты —
один исполняемый файл на Go (~40 МБ памяти), поиск идёт по индексу PostgreSQL вместо отдельного
поискового сервера, антивирус настроен так, чтобы не удваивать память при обновлении баз.

| | Минимум | Рекомендуется |
|---|---|---|
| Память | **2 ГБ** (+ файл подкачки, его создаёт установщик) | 4 ГБ |
| Процессор | 1 ядро | 2+ ядра |
| Диск | 20 ГБ + почта | SSD |

Замер на рабочем сервере (4 vCPU, 6 ГБ памяти) с **66 ГБ почты и 146 000 письмами в индексе**,
с антивирусом, антиспамом, просмотром документов и ИИ: все службы вместе держат **около 1,2 ГБ в
памяти** (и около 1,4 ГБ редко нужных данных — в основном базы антивируса — в подкачке).

Сравнение с минимумами, которые публикуют другие почтовые серверы (с антивирусом):

| | Минимум памяти |
|---|---|
| **TMail** | **2 ГБ** |
| Mailu | 3 ГБ + 1 ГБ подкачки ([документация](https://mailu.io/2024.06/compose/requirements.html)) |
| iRedMail | рекомендуется 4 ГБ ([форум](https://forum.iredmail.org/post88548.html)) |
| mailcow | 6 ГБ + 1 ГБ подкачки ([документация](https://docs.mailcow.email/getstarted/prerequisite-system/)) |

Ещё нужно:

* Публичный IPv4-адрес; Ubuntu 22.04+ или Debian 12+ (подойдут и другие Linux с Docker).
* Открытый **исходящий порт 25** (некоторые хостинги открывают его по запросу).
* Домен, DNS-записи которого вы можете менять, и обратная запись (PTR) для IP сервера (у хостинга).

## Установка

```sh
git clone https://github.com/cernos2/TMail.git /opt/tmail
cd /opt/tmail
sudo ./install.sh
```

Установщик проверит сервер, поставит Docker, спросит домен, администратора, язык интерфейса, страну
(для неё распознаются реквизиты компаний и телефоны), часовой пояс, сервис ИИ и место для резервных
копий; затем соберёт и запустит всё, создаст домен с DKIM-ключом, первый ящик и администратора и
покажет DNS-записи, которые нужно добавить. Все ответы можно передать параметрами — см.
`./install.sh --help`.

Пароли сохраняются в `/root/tmail-credentials.txt`. **Пароль резервных копий сохраните вне
сервера**: без него копии не прочитать.

### DNS-записи

| Имя | Тип | Значение |
|---|---|---|
| `mail.example.com` | A | IP сервера |
| `files.example.com` | A | IP сервера |
| `example.com` | MX | `10 mail.example.com` |
| `example.com` | TXT | `v=spf1 mx -all` |
| `<selector>._domainkey.example.com` | TXT | покажет установщик (`docker compose run --rm ctl dns example.com`) |
| `_dmarc.example.com` | TXT | `v=DMARC1; p=quarantine; rua=mailto:postmaster@example.com` |
| PTR для IP сервера | | `mail.example.com` (у хостинга) |

Админка (**Домены**) проверяет каждую запись в реальном времени. HTTPS-сертификат выпускается
сам, как только `mail.example.com` указывает на сервер.

## ИИ-помощник

Сервис выбирается в **Админка → ИИ-помощник**: OpenAI, OpenRouter (сотни моделей по одному ключу)
или своя модель за любым API, совместимым с OpenAI. Там же настраиваются имя помощника, модель по
умолчанию, отдельный API распознавания речи (у OpenRouter его нет) и все промпты. Чтобы читать сканы
и страницы PDF, модель должна понимать картинки.

## Обслуживание

```sh
cd /opt/tmail
docker compose ps                          # состояние всех служб
docker compose logs -f postfix dovecot     # журналы
alias tmail='docker compose run --rm ctl'
tmail mailbox add anna@example.com --name "Анна Смирнова"
tmail user add anna --name "Анна Смирнова" --mailboxes anna@example.com,info@example.com
tmail domain add example.org && tmail dkim gen example.org && tmail dns example.org
```

Почтовые программы: IMAP `mail.example.com:993` (SSL/TLS) или POP3 `:995`; SMTP `:465` (SSL/TLS)
или `:587` (STARTTLS); логин — полный адрес. Готовые настройки (и профиль для iPhone/Mac) каждый
найдёт в настройках веб-почты.

### Обновление

```sh
cd /opt/tmail && git pull && sudo ./install.sh --yes
```

Установщик сохраняет настройки и данные: пересобирает службы, применяет изменения базы и собирает
интерфейс заново.

### Резервные копии

`deploy/backup.sh` запускается каждую ночь (restic: инкрементно, без повторов, с шифрованием;
7 ежедневных, 4 еженедельных, 3 ежемесячных копии). Чтобы хранить их вне сервера, укажите в `.env`
`BACKUP_REPOSITORY`: S3 (`s3:https://host/bucket` и `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`)
или SFTP (`sftp:user@host:/path`). Восстановление — на том же или новом сервере:

```sh
BACKUP_REPOSITORY=… BACKUP_PASSWORD=… deploy/restore.sh --list
BACKUP_REPOSITORY=… BACKUP_PASSWORD=… deploy/restore.sh latest /opt/tmail
```
