# Translating the TMAIL interface

All text a person sees comes from `app/locales/<code>.json`: a flat map of `"area.key": "text"`.
English (`en.json`) is the base: a missing key in another language falls back to English.
Russian (`ru.json`) is the original language of the project.

## In code

```ts
import { t, num, fmtDate, monthNames, weekdayNames, tzDayKey } from '~/composables/i18n'
t('compose.send')                                   // plain text
t('list.found', { n: 12, query })                    // placeholders: "Found {n} for «{query}»"
t('list.letters', { n })                             // plurals: "{n, plural, one {# letter} other {# letters}}"
fmtDate(iso, { day: 'numeric', month: 'short' })     // dates in the user's language and time zone
num(1234.5)                                          // numbers in the user's language
```

* `t` is available in templates (`{{ t('x') }}`, `:title="t('x')"`) once imported in `<script setup>`.
* Never build a sentence from pieces: one key holds the whole sentence with placeholders, because
  word order differs between languages.
* Plurals use ICU syntax; the categories (`zero one two few many other`, or `=0`) come from
  `Intl.PluralRules` of each language. Russian needs `one few many other`, English `one other`.
* Labels in constants declared at module level (option lists, tabs…) must be computed at render
  time (`computed(() => [...])` or a function), otherwise they keep the language of the page load.
* The AI assistant's name is chosen by the administrator: write `{ai}` and pass `{ ai: aiName() }`
  (`aiName` from `~/composables/ai`).
* Server error messages are written in English in the Go code and translated in the browser by
  `app/locales/server-patterns.json` (see `composables/servermsg.ts`).

## Keys

`area.camelCaseName`, the area being the screen or component (`compose.`, `reader.`, `admin.users.` …).
Shared words live in `common.*`, dates in `date.*`, sizes in `unit.*`.
